# Roadmap

## Phase 0 — Foundation (`0.0.1-foundation`)

Module boundaries, service contracts, versioned save storage, feature flags,
diagnostics, Android landscape configuration, safe area, validation/build
tools, and tests. No player movement.

## Phase 1 — Movement laboratory (`0.1.0-movement-lab`)

Custom first-person movement, mobile/editor input sources, camera presentation,
checkpoint/respawn loop, MovementLab, feedback, diagnostics, session reports,
and movement tests.

## Phase 1B — Phone feedback and tuning (`0.1.x-movement-tuning`)

Mandatory physical Android testing. Apply only feedback-supported tuning or
confirmed fixes. Phase 2 is blocked until this is documented.

## Phase 2 — First playable levels (`0.2.0-first-levels`)

Three modular parkour levels, reusable initial block mechanics, test timing,
level selection, authoring docs, and validators. No ranks or economy.

## Phase 3 — Timer, score, and ranks (`0.3.0-ranks`)

Run timer, Bronze through Diamond thresholds, deterministic score, results HUD,
versioned progression records, and threshold tooling. Bronze always advances
the main campaign.
