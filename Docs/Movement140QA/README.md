# Movement foundation evidence

Generated in Unity 6000.5.6f1 on the development PC on 2026-09-09.
No S23 or physical-device testing occurred. validation.json records test XML
hashes, original result counts, APK metadata/hash and scripted route times.

The two MP4s are continuous segments of deterministic real CharacterController
simulation: held-only input in the existing Flow Lab bhop lane, and the first
12 seconds of the Windward normal route with an explicit input test pilot.
The pilot uses sharp view turns and corrective stick inputs; it is not present in
runtime gameplay. Encoded at 15 fps from simulation captures, not realtime FPS.
These prove visible execution, not thumb ergonomics or movement feel.

PNG selector/control views were rendered by Production099Tests. Existing art and
route geometry were retained. Full logs/XML and raw frames remain under Logs.
See ../PRODUCTION_0140.md for the S23 checklist, limitations and promotion gate.
