# Phase 3 Ranks And Progression Record

Version: `0.3.0-ranks-and-progression`  
Date: 2026-08-12  
Status: implemented on PC; physical Android testing pending

## Scope Implemented

- Run timer with `MM:SS.mmm` display.
- Restore Point split records and PB split deltas.
- Bronze, Silver, Gold, and Diamond rank evaluation.
- Data-driven uncalibrated thresholds on the first three modules.
- Deterministic score where faster comparable time means better score.
- Personal-best records and V3 save progression.
- Bronze-based derived unlocks for Modules 01 through 03.
- Results screen with Retry, Next Module, and Module Select.
- Selector progress summaries with lock state, best time, best rank, and best
  score.
- Rank calibration editor window.
- Local telemetry extension with rank, score, PB, validity, and compatibility
  metadata.

## Permanent Rule

Any valid completion of a main RYDERS BLOCK module earns at least Bronze and is
sufficient to continue the normal campaign. Higher ranks represent mastery,
never mandatory progression.

## Not Implemented

Ghosts, Personal Best ghost, Debug Trace, Error Trace, Target Trace, Crash
Wave, online leaderboards, accounts, multiplayer, economy, purchasable
power-ups, shops, advertisements, cosmetics, battle pass, final hub world,
procedural generation, final production art, and large campaign content were
not started.

## Physical Testing Required

Controls, rank thresholds, split readability, results UX, Retry speed, safe
areas, landscape-left/right, sustained 60 FPS, thermals, and module pacing must
be tested on a real Android phone before approval.
