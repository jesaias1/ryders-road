# Phase 0.5.0 - Meshy Art Kit

`0.5.0-meshy-art-kit` integrates the real Meshy environment kit for
RYDER'S ROAD while preserving the current movement, camera, save, rank,
reward, Restore, Patch, and module authoring contracts.

## Scope

- Meshy source zips and extracts are copied into
  `Assets/_Game/Art/MeshySource`; Downloads originals are not modified.
- Runtime environment prefabs, materials, textures, and cyan emission masks
  live under `Assets/_Game/Art`.
- `ModuleVisualPrefabLibrary` maps visual roles to optional prefab placements.
- `ModuleSceneController` instantiates those prefabs as visual-only children
  over existing gameplay colliders.
- `ArtKitGallery.unity` is editor-only review content and must stay out of
  Android Build Settings.
- `ART_ASSET_MANIFEST.md` records source names, canonical names, counts,
  material/prefab paths, arm candidate counts, and deferred assets.

## First-Person Arms

The production `RR_FP_Arm_Right` source is
`Meshy_AI_Neon_Vanguard_Gauntle_0818131608_texture.fbx`, copied under
`Assets/_Game/Art/MeshySource`. It imports at 15,400 triangles, 11,549
vertices, one submesh, and a 2048x2048 base texture.

Runtime arms are generated at:

- `Assets/_Game/Art/FirstPerson/Arms/PF_RR_FP_Arm_Right.prefab`
- `Assets/_Game/Art/FirstPerson/Arms/PF_RR_FP_Arm_Left.prefab`
- `Assets/_Game/Art/Generated/FirstPerson/RR_FP_Arm_Right_00.asset`
- `Assets/_Game/Art/Generated/FirstPerson/RR_FP_Arm_Left_00.asset`
- `Assets/_Game/Visuals/Resources/FirstPersonArmProfile.asset`

The left arm is generated by mirroring mesh vertices/normals/tangents on X and
reversing triangle winding; runtime transforms keep positive scale. Arms are
presentation only and must not affect movement physics or gameplay rules.

The old approximately 1.98M-triangle mech-gauntlet source may remain in
`MeshySource` as reference, but `MeshyArtKitIntegrator` ignores that legacy key
for runtime generation.

The final Surf asset is also pending; Surf presentation remains unchanged.
