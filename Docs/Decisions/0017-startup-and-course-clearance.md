# ADR 0017 — startup and course clearance

2026-09-07. Physical user feedback and screenshots authorize a bounded follow-up
to the first three levels. See S23_095_FIRST_THREE_FEEDBACK.md for reproduction and
build-identity uncertainty. No future module, motor rewrite or reward-system phase.

Top-surface raycasts and endpoint jumping did not establish clearance through a
Moving platform's whole path, nor prove that architecture stays outside block
bodies. Visible block bodies can extend below thin support colliders, so include
renderer bounds in the Moving sweep gate. Add real-scene overlap checks across each path and landing volume, paired
with traversal regressions. Keep exact mesh collision; repair placement instead.

Preserve public IDs and accepted 001. Increment 002/003 content versions for
clearance changes; retain saves and rank thresholds. Do not infer a new physics
profile or rewrite past PB metadata.

Native startup and managed scene transitions are distinct presentation intervals.
Use approved poster assets for both, retain bounded video fallback/recovery, and
validate native cold-start behavior on an actual phone. Center the existing
frontend while preserving real sequential Campaign actions.

Movement audit/design remains valid but its prior absence-of-feedback checkpoint
is superseded. Flow Lab implementation and 004–008 wait behind this physical gate.
