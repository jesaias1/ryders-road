# Changelog

## 0.0.1-foundation — 2026-07-29

### Added

- Unity 6 URP/Input System package and Android landscape project foundation.
- Explicit runtime, Editor, and test assembly boundaries.
- Bootstrap composition root and FoundationTest scene.
- Service contracts and minimal scene-loading/settings implementations.
- Versioned JSON save service with temporary writes, backup recovery,
  development reset, migration registration, and V1-to-V2 example.
- Development feature flags with release-safe behavior.
- Development diagnostics overlay and safe-area demonstration.
- Android development build command and project validation.
- Phase 0 Edit Mode and Play Mode tests.
- Architecture, save, art, testing, feedback, issue, and decision documents.

### Not added

Player movement, campaign content, ranks, ghosts, hazards, economy, power-ups,
and final artwork are intentionally outside Phase 0.
